# Kalle Knolle

Vier Rechtschreib-Lernspiele für Grundschulkinder.

| Teil | Thema |
|---|---|
| 1 | Groß- und Kleinschreibung |
| 2 | Doppelte Mitlaute (ff, ll, nn, ss, tt, mm) |
| 3 | Lange Selbstlaute: ie, stummes h, ß |
| 4 | Gleich klingende Laute: v/f, ä/e, d/t, -ig |

Die Spiele liegen verschlüsselt vor (`*.enc`, AES-256-GCM). Erst nach Eingabe des Passworts entschlüsselt der Browser das Spiel. Ohne Passwort ist der Inhalt nicht lesbar.

Hinweise: Das Vorlesen getippter Wörter nutzt meSpeak.js (eSpeak, GPL-3.0). Kalles Stimme wurde mit Piper und der Stimme „Thorsten“ (CC0) erzeugt. Die Schriften Andika und Lilita One (SIL Open Font License) sind eingebettet.
